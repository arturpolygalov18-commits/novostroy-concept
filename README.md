# НовоСтрой: концепт первых двух блоков

Демонстрационный вариант дизайна, подготовленный Артуром Полыгаловым для обсуждения с компанией. Это не официальный сайт компании и не завершённый клиентский проект.

Исходный сайт: https://novostroy.tomsk.ru/

Визуализация проекта «Алтай», логотип и фотографии строительных объектов взяты с сайта компании. Права на исходные материалы принадлежат их правообладателям. Ссылки на разделы ведут на действующий сайт компании.

Текущая версия содержит первый экран и блок выполненных объектов с переключением фотографий. Основная проработка выполнена для компьютера.
